## Local development

Work in the virtual env!
 - When starting work in this folder, run `source .venv/bin/activate`
   - Run `which python` to check -- should be in lucas-walks/backend/.venv
 - Start the backend server with `fastapi dev`
 - When done, run `deactivate`

## Dependencies
 - Packages are defined in requirements.txt
 - Install with `pip install -r requirements.txt` (make sure I'm in the virtual env!)
